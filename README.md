# AI Resume Generator 📄🤖

An intelligent, agentic resume builder that leverages cutting-edge LLMs and real-time web search to create stunning, professional resumes tailored to modern job descriptions. Built with **Streamlit**, **LangChain**, and **LangGraph/LangChain Agents**.

## 🌟 Features
* **Multi-LLM Support:** Seamlessly integrates with Google's `gemini-3.5-flash-lite` and Groq's `qwen3.6-27b` for high-quality prompt generation and content synthesis.
* **Agentic Web Search:** Uses a **Tavily AI** agent tool to fetch the latest job trends, news, and keyword requirements to make your resume stand out.
* **Dynamic HTML/CSS Output:** Generates a fully responsive, dark-themed professional resume using advanced CSS embedded directly into the Streamlit app.
* **Dynamic Prompt Engineering:** Automatically generates and optimizes complex system prompts behind the scenes using Chain-of-Thought (CoT) reasoning.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **Orchestration:** LangChain / LangChain Community Agents
* **LLMs:** Google Generative AI (Gemini) & Groq
* **Search Tool:** Tavily Client API
